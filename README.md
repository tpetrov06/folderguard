# folderguard
FolderGuard — prototype

WHAT IT DOES:
Lets you pick folders that require a face scan (via webcam) to open.
Locked folders hide themselves and stay hidden until you unlock them
by double-clicking their shortcut and looking at the camera.

HOW TO USE:
1. Move this whole folder somewhere permanent first (e.g. Desktop or
   Documents) — don't run it from Downloads or a temp folder, since
   moving it later will break any folders you've already locked.
2. Double-click FolderGuardSetup.exe
   - Windows will likely show "Windows protected your PC" — click
     "More info" then "Run anyway". This happens because the app
     isn't digitally signed, not because anything's wrong.
3. Click "Enroll Face" first — look at the camera, it captures a few
   samples.
4. Click "Add Folder" and pick a folder to protect.
5. To open a protected folder later, just double-click the shortcut
   with its name (not this exe) — it'll ask for a face scan.
6. It automatically re-locks itself after 5 minutes.
7. To stop protecting a folder, select it in this app's list and
   click "Remove Protection".

This is an early prototype — if anything breaks or looks wrong,
let Todor know exactly what you did and what happened.
